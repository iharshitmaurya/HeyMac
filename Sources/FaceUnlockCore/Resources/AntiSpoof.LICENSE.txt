Source weights: resources/anti_spoof_models/2.7_80x80_MiniFASNetV2.pth

Re-converted 2026-09-15 via PyTorch -> torch.jit.trace -> coremltools 9.0
(mlprogram, FLOAT32), with a softmax wrapper appended so the Core ML model
outputs class probabilities directly. Class index 1 = live face; indices 0 and 2
= spoof, per the upstream project's own test.py (`if label == 1: Real Face`).

Input preprocessing baked into the model: BGR channel order, raw 0-255 values
(scale 1.0, no bias). Upstream's src/data_io/functional.py to_tensor has its
`.div(255)` commented out, so the network was trained on unscaled pixels. The
2026-09-12 conversion wrongly applied a 1/255 scale, which made the model output
the same "spoof" distribution for every input.

Verified after conversion: Core ML output matches the PyTorch reference exactly
(max abs diff 0.0) on upstream's sample images (image_T1 real, image_F1/F2 fake)
and a real webcam frame, on CPU-only and all compute units.
